# Contributing

## Local development

Run a local static server from the project root:

```bash
npm run dev
```

Then open http://localhost:8000 in your browser.

## Before opening a pull request

- Keep changes focused and small.
- Preserve the existing visual language unless the change is intentionally a redesign.
- Test layout changes on desktop and mobile widths.
- Run formatting checks before submitting:

```bash
npm run format:check
```

## Pull request notes

Include a short summary of:

- what changed
- why it changed
- any visual or interaction differences
